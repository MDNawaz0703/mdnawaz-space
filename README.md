                     TITLE: Home Alarm Automation System

This project is a simple yet effective home automation and alarm system designed to enhance room security and awareness. The system simulates an automated setup where each room is equipped with a siren that triggers whenever a door is opened or lights are switched on while the user is away. The idea is to help homeowners receive instant alerts of unusual activity within their rooms, even when they’re not physically present. It demonstrates how IoT-based automation, sensor-based event detection, and alert mechanisms can be combined to create a smarter, safer living space. This project provides a foundation that can be expanded with additional modules like motion sensors, temperature monitors, or mobile notifications for a complete smart security system.

⚙️ Features

 Door Monitoring: Detects if any room door is opened while the user is away.
 Light Detection: Triggers an alert if lights are turned on unexpectedly.
 Room Sirens: Each room has an individual siren that activates upon detection of an event.
 Smart Automation Logic: Simulates a real-time home automation environment using logical control.
 Security Simulation: Demonstrates intrusion and power usage detection when the house is unattended.

 -->Tools & Technologies Used

Cisco Packet Tracer – For IoT and network simulation.

IoT Components: Sensors (Light, Door), Sirens, Smart Devices.

Networking Protocols: MQTT / IoT logical connections.

Automation Logic: Conditional triggers and alerts.

--> How It Works

Each room in the setup is equipped with a door sensor, light sensor, and a siren.

When the user leaves home, the system enters “active monitoring” mode.

If a door opens or light turns on during this state, the corresponding room’s siren automatically activates.

The system helps the user understand real-time event handling and device communication within an IoT network.

It serves as a foundation for advanced smart home systems, where additional modules (e.g., motion sensors, SMS alerts, or security cameras) can be added for complete home automation.
